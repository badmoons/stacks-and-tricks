Description

This is a stack based VM without registers (as of now at least).
So all the data is stored on a stack.
Some instructions remove elements from the stack,
but some don't and only read them or move them around.

Before using any instruction, you are expected to put load some data.
This is done with an intruction push.
This VM is not developed enough to simulate some IO, so you only can print the element that is currently currently at the top.
print also adds newlines, but that all might change.

Instructions

Note: math operations use top of the stack as a left argument, and second number as a right.

    Stack manipulation:
  • push: Put the number on top of the stack.
  • pop: Remove the number from the top.
  • dup: Copy the number at the top and put it at the top.
  • swp: Swap the top with the next element.
  • over: Swap the top with the 3rd element.
    • Math:
    All these instructions remove their operands from the stack.
  • add: Add 2 numbers on top of the stack and put the result at the top.
  • sub: Subtract 2 numbers on top of the stack and put the result at the top.
  • mul: Multiply 2 numbers on top of the stack and put the result at the top.
  • div: Divide 2 numbers on top of the stack and put the result at the top.
    • Equality:
  • gt: If the top is greater than the next element, put 1 at the top, else put 0.
  • lt: If the top is less than the next element, put 1 at the top, else put 0.
  • eq: If the top is equal to the next element, put 1 at the top, else put 0.
    • Flow control:
  • jmp: Unconditional jump to the program address located at the top.
  • jt: If 1 is at the top, jump to the address equal to the number in the next stack element.
  • jf: If 0 is at the top, jump to the address equal to the number in the next stack element.
    • Other:
  • print: print the value at the top, does not pop it.
  • nop: Does nothing, just increments the program counter. Useful to set a jump point.
